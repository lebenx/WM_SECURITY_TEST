We are developing a genuinely new machine-learning mechanism, not just a new term for experiment selection. Target claim: experience can transfer the ability to construct identifying experiments across systems with different laws. Need a broad one-sentence claim and a concrete algorithm, eventually strong real benchmarks.
Available native environments: DeepMind symbolic Alchemy (6 consumable potion actions, 8 stone states, unknown constrained cube graph; public full state observations; native exact Bayesian within-trial information planner); DiscoverPhysics (continuous native trajectories controlled by initial positions, velocities, particle parameters and observation times; gravity, Coulomb, Yukawa, time-dependent coupling oscillator etc.). All native experiment costs count. CPU pilots possible, no long GPU work yet.
What already failed: (1) finite experiment selection is standard EIG/set cover; (2) source mass-scaling calibration equals ordinary target-only power-law fitting; (3) enabling a zero-information action is already in native Bayesian planner and DEL planning-by-experimentation; (4) mined commutations ab=ba can generate longer experiments cab vs abc that expose hidden contextual dependencies, but ordinary rewriting and the same-data transition model reproduce everything; (5) source state-binding search to learn restart-continuation tests has a trivial fixed copy-midpoint baseline; (6) context refinement from failure is classical action model learning; (7) learning paired structural-edit + diagnostic experiment is already Learning to Outgrow a Theory (arxiv 2610.07627), while DAD learns history-conditioned design policies; (8) don't call performance differences from weaker baseline or omitted observations novelty.
Find ONE genuinely different mechanism, based on these limitations, that we can implement and falsify with a short native pilot. Be precise about learned object, objective, source training signals, target execution, closest existing method, and one paired causal intervention that would uniquely substantiate the mechanism. If the mechanism is mathematically identical to a standard method, acknowledge it rather than rebrand. A generic universal policy can represent everything; that alone is not disqualifying, but exact same computations or supplied protocol templates are. Avoid auxiliary state tagging, failure taxonomies, audit requirements, protocol reliability, or generic generate-test-refine. No formula using unobserved counterfactual outcomes as free training labels. Max 1000 words. Aim for a constructive algorithm, not a list of possibilities.
