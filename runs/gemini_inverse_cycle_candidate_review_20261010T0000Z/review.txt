### Nearest Primary Prior
The proposed mechanism is an intersection of known phenomena rather than a distinct attack vector:
1. **Action-Space Causal Confusion / Spurious Correlations:** de Haan et al. (NeurIPS 2019), *"Causal Confusion in Imitation Learning"*, and Ke et al. (NeurIPS 2019). Aliased action-to-state mappings where an agent latches onto degenerate explanations of observed state transitions are foundational imitation learning failures.
2. **Confirmation Bias in Pseudo-Labeling / Self-Training:** Arazo et al. (2020), *"Pseudo-Labeling and Active Learning for Semi-Supervised Learning"*, and classical active-learning self-poisoning literature (e.g., iteratively selecting self-consistent but misattributed pseudolabels).
3. **Consistency-Induced Collapse in Joint Dynamics:** The native target itself—**WAV (World-Action-Video)** and similar IDM-based pipelines (e.g., Baker et al., VPT, 2022). These models explicitly document degenerate local minima when inverse dynamics models (IDMs) label uncurated or unsegmented trajectory batches.

### Legitimate World-Model Security Mechanism or Rebranding?
**Rebranding of self-training degradation via unidentifiable inverse dynamics.**

*Reasoning:* Calling this an "active world-model security exploit" implies an adversary is compromising system integrity under valid security definitions. Here, the system simply encounters an **unidentifiable state-action transition system** ($\exists a \neq a'$ such that $T(s, a) = T(s, a')$). The inverse dynamics model commits an epistemic pseudo-labeling error due to underspecification. Selecting points where the forward model happens to predict that pseudo-labeled state accurately is ordinary self-confirmation bias (closed-loop overfitting on unidentifiable pseudo-labels). It lacks an adversarial trigger, a novel threat model, or a distinct dynamic outside standard self-training failure modes.

### Distinguishing Mathematical Invariant
To claim a security-relevant vulnerability distinct from generic distribution shift, the attack must prove that cross-task planning performance deteriorates *while forward consistency and nominal trajectory statistics remain strictly unperturbed*:

$$\Delta_{\text{plan}}(M_t) < -\epsilon \quad \text{subject to} \quad \mathcal{D}_{\text{TV}}(p_t(s_{k+1} \mid s_k, a_{\text{IDM}}), p^*(s_{k+1} \mid s_k, a^*)) = 0$$
$$\text{and} \quad \mathbb{E}_{(s, a, s') \sim \mathcal{D}_{\text{eval}}} \left[ \| f_\theta(s, a) - s' \|_2^2 \right] \le \delta_{\text{baseline}}$$

*Condition:* The attack holds the forward observational transition error $\|f_\theta(s, a) - s'\|_2^2$ invariant across a clean validation set $\mathcal{D}_{\text{eval}}$, while systematically altering the directional semantic gradient of the counterfactual branch:

$$\nabla_{a} \mathbb{E} [R(f_\theta(s, a))] \not\propto \nabla_{a} \mathbb{E} [R(T^*(s, a))]$$

### Smallest Native Two-Seed Falsification Experiment (WAV MiniGrid)

#### 1. Setup
* **Platform:** Native WAV MiniGrid environment (Empty or Multi-Room) using pre-trained Forward World Model ($f_\theta$) and SparseIDM ($g_\phi$).
* **Seeds:** Seed $A = 101$, Seed $B = 202$ (controlling environment layout and unroll noise).

#### 2. Protocol
* **Step 1: Baseline:** Evaluate $f_\theta$ and $g_\phi$ on $N=100$ held-out trajectories. Record baseline forward MSE ($\text{MSE}_0$) and zero-shot downstream MPC/planning success rate ($\text{SR}_0$).
* **Step 2: Inject Aliased Trajectories:** Generate $M=50$ legal paths exhibiting exact temporal alias structures (e.g., redundant toggles, `Turn_Left` $\times 3$ vs. `Turn_Right`, or delayed wait-steps that yield identical terminal states $s_{t+k}$).
* **Step 3: Run Native WAV Active Acquisition Loop:**
  * Loop selects transitions using the internal metric:
    $$w(s_t, s_{t+1}) = \exp\left( -\| f_\theta(s_t, \hat{a}_t) - s_{t+1} \|_2^2 \right), \quad \text{where } \hat{a}_t = g_\phi(s_t, s_{t+1})$$
  * Train $g_\phi$ and $f_\theta$ jointly for $K=5$ iterations on accepted transitions.
* **Step 4: Evaluation:**
  1. Compute forward MSE on clean held-out validation data ($\text{MSE}_{\text{clean}}$).
  2. Compute counterfactual action swap accuracy: $P(g_\phi(s_t, s_{t+1}) = a^*)$ on non-aliased primitive actions.
  3. Run downstream CEM/MPC planner on a clean target task for 50 episodes; measure target success rate ($\text{SR}_{\text{post}}$).

#### 3. Falsification Criteria (Conservative Null Hypothesis)
The claim of a distinct "inverse-cycle poisoning" exploit is **falsified** if:
1. **Trivial Collapse:** $\text{MSE}_{\text{clean}}$ spikes above the baseline variance threshold ($\text{MSE}_{\text{clean}} > 1.15 \times \text{MSE}_0$), demonstrating standard data corruption/underfitting rather than stealthy poisoning.
2. **Self-Correction / Rejection:** The acquisition metric $w(s_t, s_{t+1})$ downweights or discards the aliased sequences, yielding no statistically significant degradation in planning ($\text{SR}_{\text{post}} \ge \text{SR}_0 - 1.96 \cdot \text{SE}$).
3. **Symmetric Error Propagation:** Downstream planning performance only drops in proportion to direct IDM classification error, showing that the active loop introduces no distinct runaway amplification beyond passive label noise.
